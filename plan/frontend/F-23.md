## Deskripsi
Final performance and UX optimization pass guaranteeing 60fps butter-smooth animations on low-end mobile devices ("HP Kentang") and flawless Full Light Mode presentation.

## Detail Teknis
- **Adaptive Blur Engine (Low-End Hardware Degradation)**:
  - Implement a performance detection hook (checking `navigator.hardwareConcurrency <= 4`, reduced motion preference, or frame-drop detection). On high-end devices, full Liquid Glass `backdrop-blur-md` is active. On low-end mobile devices ("HP kentang"), automatically degrade blurs to solid opaque frosted surfaces (`bg-white/95` with specular border) to guarantee 0 lag and cool CPU/GPU temperatures!
- **Strict Hardware-Accelerated Animations**:
  - Enforce that 100% of UI animations (bottom sheets, slide-over drawers, navbar auto-hide) manipulate ONLY GPU-friendly properties (`transform: translate3d(x,y,z)`, `scale()`, `opacity`). Zero CSS layout animations on `width`, `height`, `margin`, or `padding` allowed.
- **Optimistic UI & Offline Caching**:
  - Implement Optimistic UI updates across checkbox toggles, infaq inputs, and CRUD operations for zero perceived latency.
  - Test offline caching banner ("⚡ Sinyal terputus...") across mobile breakpoints.
- **Responsive Breakpoint Verification**:
  - Strict audit across mobile viewports (375px, 390px, 768px) and desktop (1024px, 1440px+). Ensure no text-selection clipping (`select-none`), touch hit targets >= 44x44px, loading skeletons, custom empty state illustrations, and clean `@media print` styles in Full Light Mode (`#F7F5F0`).

## Acceptance Criteria
- [ ] Adaptive Blur Engine successfully switches to solid frosted surface on low-end hardware without visual breakage
- [ ] 100% of animations run at 60fps using GPU-accelerated CSS properties
- [ ] Optimistic UI updates provide instant visual feedback before server confirmation
- [ ] Zero layout breaks, text-selection bugs, or dark mode artifacts across all mobile and desktop breakpoints
