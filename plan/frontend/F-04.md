## Deskripsi
Shared login page for admin and wali.

## Detail Teknis
pages/auth/LoginPage.tsx. Form: username/email + password. Submit → POST /auth/login → store tokens → redirect based on role (admin → /admin/dashboard, wali → /wali/dashboard). Show error on invalid credentials. School logo and name from settings (or fallback). Clean, professional design.

## Acceptance Criteria
- [ ] Login works for both roles
- [ ] Tokens stored
- [ ] Correct redirect
- [ ] Error handling
- [ ] Looks good
