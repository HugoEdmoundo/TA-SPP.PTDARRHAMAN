## Deskripsi
High-productivity financial command center for school administrators in Full Light Mode (PTDARRAHMAN Ivory/Emerald palette).

## Detail Teknis
- **`pages/admin/DashboardPage.tsx` (E-Trading Command Center Layout)**:
  - **Spotlight Search Bar & Keyboard Shortcuts**: Prominent top search bar with `Ctrl+K` / `Cmd+K` trigger for instant global navigation to any student or bill. Supports power-user shortcuts (`N` for new bill, `E` for export).
  - **Liquid Glass Stat Cards**: Row of cards displaying Total Masuk Bulan Ini (with trend indicator & emerald glow), Siswa Lunas, Siswa Nunggak (with crimson alert badge), and Total Infaq. Uses `bg-white/80 backdrop-blur-md` with 1px specular borders on `#F7F5F0` background.
  - **Grid Breakdown Table**: Summary table comparing SPP / Non-SPP / Event / Infaq across Payment Gateway vs Manual collection.
  - **6-Month Trend Chart**: Clean Recharts line/area chart styled in brand Emerald Green (`#1A6B47` and `#22C55E`).
  - **Quick Action Trigger Drawers**: Buttons for "+ Tagihan Non-SPP", "+ Event Baru", and "Input Pembayaran" instantly open slide-over right drawers without navigating away from the dashboard.

## Acceptance Criteria
- [ ] Stat cards render in Liquid Glass aesthetic with accurate trend indicators
- [ ] `Ctrl+K` / `Cmd+K` spotlight search and keyboard shortcuts function smoothly
- [ ] Chart renders cleanly with PTDARRAHMAN Emerald color styling in Full Light Mode
- [ ] Quick action buttons trigger slide-over drawers without full page reloads
