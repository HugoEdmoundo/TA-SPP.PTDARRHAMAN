## Deskripsi
Admin configuration page with flexible logo upload and real-time settings management.

## Detail Teknis
- **`pages/admin/SettingsPage.tsx` (Liquid Glass Tabs)**:
  - Tab 1: **Profil Sekolah** (form: nama, alamat, telp, email, dan **Flexible Logo Input**: admin bebas upload file gambar lokal ATAU copas direct image URL dengan fitur instant live preview!).
  - Tab 2: **SPP** (nominal bulanan, tanggal jatuh tempo, tahun ajaran).
  - Tab 3: **Rekening Bank** (CRUD table: bank name, account number, holder name, active toggle).
  - Tab 4: **Kuitansi** (format nomor kuitansi, nama & ttd penandatangan).
  - Each tab auto-saves or has a dedicated save button with Optimistic UI feedback and Toast notification.

## Acceptance Criteria
- [ ] All settings CRUD works smoothly
- [ ] Flexible Logo Input works for both local file upload and direct image URL copy-paste with instant preview
- [ ] Bank accounts CRUD works
- [ ] Changes persist accurately across sessions
