## Deskripsi
High-performance student data management with virtualized rendering and seamless slide-over drawers.

## Detail Teknis
- **`pages/admin/StudentsPage.tsx` (Zero-Lag Table with Virtualization)**:
  - Implement **Virtual Scrolling (`@tanstack/react-virtual`)** on the student table. Only renders visible DOM rows (15-20 rows) at a time, guaranteeing 60fps scrolling and 0 lag even when handling 5,000+ students on low-end devices/laptops.
  - Columns: NIS, Nama, Gender, Tahun Masuk, Status (with gold/emerald badges), Actions.
  - Controls: Search bar (integrated with global Spotlight search), filter by active/inactive/kelas, and **Comfort vs Dense View Toggle** (allows admin to switch between spacious padded rows and compact Excel-style rows for speed browsing).
- **Slide-Over Right Drawer Workflow (No Page Redirects)**:
  - Clicking a student row opens a **Slide-over Right Drawer (`StudentDetailDrawer.tsx`)** from the right side of the screen instead of navigating away. Shows student info, linked parents, 3-year payment summary, and quick edit form without losing table context!
- **Import Modal (`StudentImportModal.tsx`)**:
  - Button "Import CSV/Excel" → opens Liquid Glass modal: drag-and-drop file upload → instant preview table with validation errors highlighted in crimson red → confirm import with optimistic feedback toast.

## Acceptance Criteria
- [ ] Virtual scrolling (`@tanstack/react-virtual`) implemented and tested for smooth 60fps rendering with large datasets
- [ ] Clicking student row opens slide-over right drawer without page reload
- [ ] Comfort vs Dense view toggle changes table row height and padding
- [ ] CSV/Excel import preview highlights validation errors before submission
