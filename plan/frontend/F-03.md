## Deskripsi
Adaptive layouts maximized for both Native-like Mobile UX (Wali) and Widescreen Desktop Command Center (Admin) in Full Light Mode, with real-time SSE logo syncing.

## Detail Teknis
- **Real-Time Logo & Favicon Syncing via SSE (Server-Sent Events)**:
  - Both layouts dynamically load school branding via `getSettings()`, checking setting keys in order: `logo` → `favicon` (using standard fallback without hardcoded paths).
  - Listens to **SSE (`EventSource` connecting to `/api/v1/settings/events` or equivalent)** for real-time updates. When admin updates logo or school profile in settings, all connected dashboards instantly update their logos and headers without refreshing!
- **`components/layout/WaliLayout.tsx` (Native Mobile-First UX)**:
  - Header: Clean PTDARRAHMAN branding with dynamic logo (`w-9 h-9 object-contain`), interactive child selector badge (if >1 child), offline resilience banner (auto-appears when signal drops), profile & logout.
  - **Telegram-Style Smart Bottom Navbar (Mobile)**: Fixed at bottom with safe-area padding (`pb-safe`). Intercepts scroll events (throttled): scrolling down > 20px smoothly slides the navbar down out of view (`translate-y-full opacity-0 duration-300`) to maximize screen content focus; scrolling up even 5px instantly slides it back up (`translate-y-0 opacity-100`).
  - Icons feature active haptic-like scale feedback (`active:scale-90`) and glowing emerald indicator dots for the active tab.
- **`components/layout/AdminLayout.tsx` (Widescreen Desktop Command Center)**:
  - **Collapsible Liquid Glass Sidebar**: Can toggle between full-width menu and mini icon-only collapsed mode to maximize screen real estate for dense finance tables. Header displays dynamic logo and PTDARRAHMAN text. Menu items: Dashboard, SPP, Tagihan Non-SPP, Event, Pembayaran, Laporan, Audit Log, Settings, Data Siswa, Data Wali.
  - Header: User profile, quick school profile switcher, and **Spotlight Search Bar / Trigger (`Ctrl+K` / `Cmd+K`)** for instant global navigation. No dark mode toggle (Full Light Mode only).
  - Responsive: Automatically collapses to bottom sheet or drawer menu on tablet/mobile screens.

## Acceptance Criteria
- [ ] Dynamic logo loading works across both layouts, syncing with `getSettings()` and updating in real-time via SSE
- [ ] WaliLayout features working Telegram-style auto-hide/show Bottom Navbar on scroll
- [ ] AdminLayout sidebar cleanly collapses to icon-only mode for wide table viewing
- [ ] Safe-area padding (`pb-safe`) and touch anti-selection (`select-none`) properly applied
- [ ] Full Light Mode styling consistent across both layouts with Ivory (`#F7F5F0`) background
