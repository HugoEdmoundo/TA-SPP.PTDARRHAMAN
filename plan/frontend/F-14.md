## Deskripsi
Native-like mobile dashboard for parents/wali, featuring E-Wallet aesthetics, swipeable tabs, offline resilience, and anti-gaptek onboarding.

## Detail Teknis
- **`pages/wali/DashboardPage.tsx` (E-Wallet Style Mobile Experience)**:
  - **1-Minute Onboarding Tooltip (Anti-Gaptek)**: Detects first-time login and shows a simple 2-step visual guidance overlay ("👉 Klik di sini untuk pilih anak" and "👉 Centang tagihan lalu tekan Bayar"). Never shown again once dismissed.
  - **Header & Child Selector**: Liquid Glass summary card showing total outstanding balance in Inter typography. If >1 child, clicking child selector opens a **Slide-up Bottom Sheet** (instead of a web dropdown) with student names, NIS, and class badges.
  - **Offline Resilience Banner**: If connection drops, displays a soft gold banner ("⚡ Sinyal terputus, menampilkan data terakhir yang tersimpan...") while keeping cached bills interactive.
  - **Swipeable Tabs & Touch-First Lists**:
    - Users can swipe left/right to toggle between: 1) Tagihan SPP, 2) Tagihan Non-SPP, 3) Patungan / Event (with progress bar).
    - All list items use `user-select: none` (`select-none`) and minimum 44x44px touch hit-targets to prevent accidental browser text selection or miss-clicks.
  - **Pull-to-Refresh**: Native pull-down gesture to refresh bill status from the server.
  - **Floating Action Checkout Bar**: Fixed above the bottom navbar, displays live selected items count and a prominent Emerald Green "Bayar Sekarang" button → triggers slide-up Checkout Bottom Sheet.

## Acceptance Criteria
- [ ] 1-Minute onboarding tooltip displays on first login and persists dismissal
- [ ] Child selector opens via slide-up bottom sheet with drag handle
- [ ] Swipeable tabs and pull-to-refresh gestures work smoothly on mobile
- [ ] Offline banner appears gracefully during network disconnects
- [ ] Touch hit targets meet 44x44px Apple HIG standard with anti-text-selection enabled
