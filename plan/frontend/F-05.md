## Deskripsi
AuthContext and route protection.

## Detail Teknis
contexts/AuthContext.tsx — provide user state, login/logout functions, token refresh. Store tokens in localStorage. Auto-refresh before expiry. components/auth/ProtectedRoute.tsx — check auth, check role, redirect to login if not authenticated, redirect to 403 if wrong role. api/client.ts — add Authorization header interceptor, auto-refresh on 401. Setup React Router in App.tsx with nested routes: /auth/*, /admin/* (ProtectedRoute role=admin), /wali/* (ProtectedRoute role=wali).

## Acceptance Criteria
- [ ] Protected routes work
- [ ] Unauthorized users redirected
- [ ] Token auto-refresh works
- [ ] Role-based access enforced
