## Deskripsi
Event list, create, and tracking.

## Detail Teknis
pages/admin/EventsPage.tsx — tabs: Active Events, History. Active tab: cards for each event showing name, progress bar, total collected/target, deadline. Click → EventDetailPage.tsx: event info, tracking table (student, target, paid, remaining, installments count, status per student), progress bar, complete event button. Button "+ Buat Event" → form: name, description, per_student_amount, select students (multi-select), deadline, allow installment, min installment amount.
