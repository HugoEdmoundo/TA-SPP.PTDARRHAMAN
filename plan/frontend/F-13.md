## Deskripsi
Admin records payment.

## Detail Teknis
pages/admin/PaymentPage.tsx or modal accessible from multiple pages. Step 1: Search/select student (autocomplete by name or NIS). Step 2: Select payment type (SPP / Non-SPP / Event). If SPP → show grid of unpaid months, select month(s). If Non-SPP → show list of unpaid bills, select bill. If Event → show list of unpaid event bills, select bill. Step 3: Input amount (can be partial = cicilan), method (cash/transfer), infaq (optional), notes. Step 4: Review & confirm. After confirm → show success + print receipt button.

## Acceptance Criteria
- [ ] Multi-step form works
- [ ] All payment types supported
- [ ] Partial payment (cicilan) works
- [ ] Receipt printable after payment
