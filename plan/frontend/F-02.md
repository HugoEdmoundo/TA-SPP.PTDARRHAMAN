## Deskripsi
Design tokens, PTDARRAHMAN Islamic/Pesantren modern identity, Liquid Glass UI aesthetics (Full Light Mode Only), and interactive base UI components.

## Detail Teknis
- **Theme & Color System (Full Light Mode Only - No Dark Mode)**: 
  - Adopt PTDARRAHMAN brand identity in `tailwind.config.ts`:
    - `bg-ivory`: `#F7F5F0` (Main background, warm porcelain/cream feel).
    - `bg-elevated`: `#FFFFFF` (Cards and Liquid Glass surfaces).
    - `text-obsidian`: `#1A1A1A` (High-contrast readability), `text-slate`: `#6B6B6B`.
    - `primary-emerald`: `#1A6B47` (Brand identity), `emerald-bright`: `#22C55E` (Success/Paid badge, interactive glow).
    - `accent-gold`: `#D4A853` (Prestige/VIP/Cicilan badge), `gold-light`: `#F0C878`.
    - `danger-rose`: `#FF3B30` (Menunggak/Overdue).
- **Typography**: Combine **Plus Jakarta Sans / Outfit** (modern clean headings) with **Inter** (high legibility for nominal Rp & financial tables).
- **Liquid Glass Aesthetics**: Card and container styling using `bg-white/70` to `bg-white/80` with `backdrop-blur-md` (12px blur), 1px specular border reflection (`border border-white/60 shadow-[0_8px_32px_rgba(26,107,71,0.06)]`), and subtle glowing accents (`--glow-emerald`, `--glow-gold`).
- **Base UI Components (`components/ui/`)**:
  - `Button.tsx`: Variants (emerald-primary, gold-accent, outline, ghost, danger), active scale feedback (`active:scale-95`), min hit-target 44x44px for touch accessibility.
  - `InputCurrency.tsx`: Real-time Indonesian Rupiah formatter (`Rp 1.500.000`) paired with **Quick-Chip Nominal Buttons** (`[+Rp 50.000]`, `[+Rp 100.000]`, `[+Rp 500.000]`, `[Bayar Semua]`) to eliminate zero-typing errors on mobile keypads.
  - `LogoInput.tsx / FileUpload.tsx`: **Flexible Logo / Image Input** supporting both local drag-and-drop file upload AND direct external image URL copy-pasting ("copas URL") with instant live preview and auto-fallback!
  - `Card.tsx`, `Badge.tsx` (with subtle pulse animation for urgent overdue bills), `BottomSheet.tsx` (slide-up sheet with drag handle and swipe-down dismiss for mobile, replacing centered modals), `Table.tsx`, `Toast.tsx` (offline resilience & transaction feedback), `Spinner.tsx`, `EmptyState.tsx`.
  - `ReceiptShareCard.tsx`: **WhatsApp-Friendly Digital Receipt Card** (vertical 9:16 / square ratio) with school logo, QR verification, emerald "LUNAS" stamp, and 1-click "Kirim ke WhatsApp / Simpan PNG" action.

## Acceptance Criteria
- [ ] All base components built with Liquid Glass aesthetic in Full Light Mode (`#F7F5F0` background)
- [ ] PTDARRAHMAN Emerald (`#1A6B47`) and Gold (`#D4A853`) palette correctly configured
- [ ] InputCurrency with Quick-Chip nominal buttons works smoothly
- [ ] LogoInput supports both file uploads and direct URL copy-pasting with live preview
- [ ] ReceiptShareCard renders cleanly and supports 1-click image download/share
- [ ] Touch hit-targets meet 44x44px minimum and `user-select: none` (`select-none`) applied on UI controls
