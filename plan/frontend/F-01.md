## Deskripsi

Setup folder structure: pages/admin/, pages/wali/, components/ui/, components/layout/, contexts/, api/, types/, utils/.

## Detail Teknis

- Setup API client in `api/client.ts` with base URL from env, interceptor for JWT token. Create `types/index.ts` with TypeScript interfaces matching backend models.
