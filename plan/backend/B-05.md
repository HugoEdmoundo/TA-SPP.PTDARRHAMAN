## Deskripsi
Helper function untuk upload file (logo sekolah, lampiran non-SPP, foto siswa).

## Detail Teknis
Create `app/utils/upload.py`.
Function `save_upload(file: UploadFile, subfolder: str) -> str`.
Saves to `uploads/{subfolder}/{uuid}_{filename}`.
Validate file type and size.
Endpoint GET `/uploads/{path}` to serve files.
Create `uploads/` directory if not exists.

## Acceptance Criteria
- [ ] Can upload image/pdf files
- [ ] Get back URL path
- [ ] Serve files via endpoint
