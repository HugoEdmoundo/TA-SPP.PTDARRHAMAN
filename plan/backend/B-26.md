## Deskripsi
Return dashboard data with SSE-driven real-time auto-refresh support.

## Detail Teknis
- GET `/dashboard/admin` — return: {total_income_this_month, students_paid_count, students_unpaid_count, total_students, infaq_this_month, breakdown: {gateway: {spp, non_spp, event, infaq}, manual: {spp, non_spp, event, infaq}}, trend_6_months: [{month, year, total}], active_events: [{id, name, progress_pct}]}.
- **SSE Auto-Refresh Integration**:
  - When `payment_success` SSE event is broadcasted (from B-18 webhook callback), the frontend dashboard will automatically re-fetch this endpoint to refresh all stat cards, breakdown table, and trend chart in real-time without manual page reload.
  - Backend ensures the GET `/dashboard/admin` query is optimized for frequent calls (proper DB indexing, avoid N+1 queries, consider caching with short TTL for heavy aggregations).

## Acceptance Criteria
- [x] All stats accurate
- [x] Breakdown by channel × type correct
- [x] Trend data for last 6 months
- [x] Query performance optimized for frequent SSE-triggered re-fetches (< 200ms response time)
