# B-15 — Event tracking

| | |
|---|---|
| **Fase** | 3: Core Billing |
| **Type** | Backend |
| **Dependencies** | B-14 |
| **Status** | ⬜ Belum Mulai |

---

## Deskripsi
Progress per siswa, total collected.

## Detail Teknis
GET `/events/:id/tracking` — return {event info, total_target, total_collected, progress_pct, students: [{student_id, name, target, paid, remaining, installment_count, status}]}.
POST `/events/:id/complete` — set status to completed (only if active).

## Acceptance Criteria
- [ ] Tracking shows accurate per-student progress
- [ ] Complete action works
- [ ] Cannot complete draft events
