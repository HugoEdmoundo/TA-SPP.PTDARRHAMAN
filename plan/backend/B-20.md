## Deskripsi
Service layer: hitung status bill, track cicilan.

## Detail Teknis
`app/services/installment.py`.
Functions:
`calculate_bill_status(bill_id)` → recalculate total_paid and status.
`validate_installment(bill_id, amount)` → check min installment for events.
`get_installment_history(bill_id)` → list all payments for a bill.
For SPP: calculate based on payments WHERE payment_type='spp' AND spp_month=X AND spp_year=Y.

## Acceptance Criteria
- [ ] Bill status correctly calculated after each payment
- [ ] Min installment validated for events
- [ ] Installment history accurate
