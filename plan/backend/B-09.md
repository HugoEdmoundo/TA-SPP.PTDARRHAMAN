## Deskripsi
Endpoint POST `/students/import` — terima file Excel/CSV, parse, validate, preview, confirm import.

## Detail Teknis
`app/routes/students.py` (add import endpoint).
POST `/students/import/preview` — upload file, parse, return preview data + validation errors.
POST `/students/import/confirm` — accept previewed data, bulk insert.
Use `openpyxl` for Excel, `csv` module for CSV.
Validate required fields (NIS, full_name). Check for duplicate NIS.

## Acceptance Criteria
- [ ] Upload CSV/Excel → get preview with errors
- [ ] Confirm → students created
- [ ] Duplicates rejected
