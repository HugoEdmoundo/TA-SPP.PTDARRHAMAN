## Deskripsi
Admin CRUD users: buat akun admin/wali, edit, nonaktifkan, reset password.

## Detail Teknis
`app/routes/users.py`.
GET `/users` (list, filter by role, search).
POST `/users` (create, auto-hash password).
PUT `/users/:id` (edit profile).
DELETE `/users/:id` (soft delete / deactivate).
POST `/users/:id/reset-password` (admin resets).
All admin-only.

## Acceptance Criteria
- [ ] Admin can create wali accounts
- [ ] Admin can edit, deactivate, reset passwords
- [ ] Wali cannot access these endpoints
