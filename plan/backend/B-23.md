## Deskripsi
Generate kuitansi dalam 2 format: PDF (formal/arsip) dan PNG image (WhatsApp-friendly sharing). Sequential numbering.

## Detail Teknis
- **`app/services/receipt.py`** (Dual-Format Receipt Generation):
  - `generate_receipt_pdf(payment_id)` → creates formal PDF using `reportlab` or `fpdf2` with: school header (logo + name from settings), student info, payment details, infaq, total, receipt number (KWT/YYYY/MM/NNN), date.
  - `generate_receipt_image(payment_id)` → creates **WhatsApp-friendly PNG image** using `Pillow` (PIL). Renders a clean vertical card (9:16 or square aspect ratio) in PTDARRAHMAN Ivory/Emerald palette featuring: school logo, student NIS & name, itemized payment breakdown, QR verification code (using `qrcode` library), emerald "LUNAS" stamp, receipt number, and date. Optimized for mobile viewing and social media sharing.
  - GET `/receipts/:payment_id/pdf` — serve PDF file.
  - GET `/receipts/:payment_id/image` — serve PNG image file (for 1-click WhatsApp sharing / download).
  - Receipt number: auto-increment per month. Store in receipts table.

## Acceptance Criteria
- [x] PDF generated with correct data and school branding
- [x] PNG image generated with PTDARRAHMAN Emerald/Ivory styling and QR code
- [x] Receipt number sequential (KWT/YYYY/MM/NNN)
- [x] School header dynamically loaded from settings
- [x] Both PDF and PNG downloadable via separate endpoints
