## Deskripsi
Daftar event selesai. Detail + summary cicilan per siswa.

## Detail Teknis
GET `/events/history` — list events WHERE status='completed'.
GET `/events/:id/history` — return event detail + per student: {name, total_paid, installments: [{date, amount, method}], total_installments}.

## Acceptance Criteria
- [ ] History shows completed events
- [ ] Per-student installment summary correct
