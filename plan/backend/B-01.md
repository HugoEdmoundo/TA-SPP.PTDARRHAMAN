## Deskripsi
Finalisasi folder structure FastAPI: app/, routes/, schemas/, services/, utils/. Install semua dependencies dari requirements.txt.

## Detail Teknis
Create folders `app/routes/`, `app/schemas/`, `app/services/`, `app/utils/`. Each with `__init__.py`.
Verify `requirements.txt` has: fastapi, uvicorn, sqlmodel, sqlalchemy, alembic, psycopg2-binary, python-jose, passlib, python-multipart, python-dotenv, pydantic-settings.

## Acceptance Criteria
- [ ] Project runs with `uvicorn main:app`
