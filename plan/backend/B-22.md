## Deskripsi
Wali pilih tagihan, hitung total, trigger gateway.

## Detail Teknis
POST `/my/checkout` — body: {child_id, items: [{type, month/year or bill_id}], infaq_amount}.
Validate parent-student link. Validate items exist and are unpaid/partial. Calculate total. Call payment gateway service. Return redirect URL.

## Acceptance Criteria
- [ ] Wali can checkout multiple items at once
- [ ] Validates ownership
- [ ] Infaq added to total
- [ ] Returns gateway redirect
