## Detail Teknis
Models needed:
- User: id, username, email, hashed_password, full_name, phone, role (admin/wali), is_active, created_at, updated_at
- Student: id, nis (unique), full_name, gender, birth_place, birth_date, address, phone, academic_year (tahun masuk), photo_url, is_active, created_at, updated_at
- ParentStudent: id, parent_id (FK users), student_id (FK students) — many-to-many link table
- SppSetting: id, monthly_nominal (Decimal), due_day (int, tanggal jatuh tempo), academic_year, is_active, effective_from, effective_to, notes, created_at, updated_at
- Bill: id, student_id (FK), bill_type (enum: non_spp/event), label, description, category (for non_spp), attachment_url, amount (Decimal), total_paid (Decimal), status (enum: unpaid/partial/paid), due_date, event_id (FK nullable), notes, created_at, updated_at. NOTE: SPP bills are VIRTUAL — not stored. Only non_spp and event bills are stored.
- Event: id, name, description, per_student_amount (Decimal), total_target (Decimal), total_collected (Decimal), status (enum: draft/active/completed/cancelled), deadline, allow_installment (bool), min_installment_amount (Decimal nullable), created_by (FK users), created_at, updated_at
- Payment: id, student_id (FK), bill_id (FK nullable — null for SPP since SPP has no bill record), payment_type (enum: spp/non_spp/event), spp_month (int nullable, 1-12), spp_year (int nullable), amount (Decimal), infaq_amount (Decimal default 0), total_amount (Decimal — amount + infaq), method (enum: cash/transfer), channel (enum: gateway/manual), gateway_transaction_id (str nullable), notes, created_by (FK users nullable — admin who recorded it), created_at. NO status field — all payments are auto-confirmed.
- Receipt: id, payment_id (FK), receipt_number (str unique, e.g. KWT/2025/07/001), pdf_url, is_void (bool default false), void_reason, voided_by (FK users nullable), voided_at, created_at
- SchoolSetting: id, key (str unique), value (text), created_at, updated_at — key-value store for school profile, SPP config, etc.
- BankAccount: id, bank_name, account_number, account_holder, is_active, created_at, updated_at
- AuditLog: id, user_id (FK nullable), action (str), entity_type (str), entity_id (int nullable), detail (text), ip_address (str nullable), created_at
