## Deskripsi
Integrasi Midtrans/Xendit dengan real-time SSE broadcasting setelah payment berhasil.

## Detail Teknis
- **`app/services/payment_gateway.py`**:
  - POST `/payments/gateway/create` — body: {student_id, items: [{type: 'spp', month, year} or {type: 'non_spp', bill_id} or {type: 'event', bill_id}], infaq_amount}.
  - Calculate total. Create gateway transaction. Return {redirect_url, transaction_id}.
  - POST `/payments/gateway/callback` (webhook) — verify signature, create Payment records, update bill statuses, auto-generate receipt (PDF + PNG).
  - Use Midtrans Snap or Xendit Invoice API.
- **SSE Broadcast on Payment Success**:
  - After webhook callback successfully processes a payment, broadcast SSE event via the `ConnectionManager` (from B-04):
    - `{"type": "payment_success", "student_id": <id>, "payment_id": <id>, "total": <amount>}` → triggers real-time UI updates on:
      - **Wali dashboard**: Bill badge instantly changes from Red (Unpaid) to Emerald Green (Lunas) without page refresh.
      - **Admin dashboard**: Stats auto-refresh (total masuk, siswa lunas count, etc.).
      - **Admin SPP Grid**: Cell color updates in real-time.

## Acceptance Criteria
- [ ] Can create payment via gateway
- [ ] Webhook correctly processes callback
- [ ] Payment records created
- [ ] Bill statuses updated
- [ ] Receipt generated (PDF + PNG)
- [ ] SSE event `payment_success` broadcasted to all connected clients after successful webhook
