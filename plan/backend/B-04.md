## Deskripsi
CRUD endpoint untuk konfigurasi: profil sekolah (nama, alamat, logo, telp), nominal SPP, jatuh tempo, rekening bank, format kuitansi. Includes SSE (Server-Sent Events) infrastructure for real-time broadcasting and flexible logo input (file upload OR direct URL).

## Detail Teknis
- **Routes in `app/routes/settings.py`**:
  - Endpoints: GET `/settings` (all), PUT `/settings/:key` (update), GET `/settings/:key`.
  - **Flexible Logo Input**: `PUT /settings/logo` accepts BOTH:
    1. **File upload** (`multipart/form-data`) → saves via `save_upload()` utility, stores resulting URL.
    2. **Direct URL string** (`application/json` body `{value: "https://..."}`) → validates URL is a reachable image, stores URL as-is.
  - CRUD for bank accounts: GET `/bank-accounts`, POST `/bank-accounts`, PUT `/bank-accounts/:id`, DELETE `/bank-accounts/:id`.
  - CRUD for SPP settings: GET `/spp-settings`, POST `/spp-settings`, PUT `/spp-settings/:id`.
- **SSE (Server-Sent Events) Infrastructure** in `app/routes/sse.py`:
  - GET `/sse/events` → `EventSourceResponse` (text/event-stream). Clients connect and stay subscribed.
  - Use `asyncio.Queue` per connected client (managed via a global `ConnectionManager` class).
  - When any setting is updated via `PUT /settings/:key`, broadcast SSE event `{"type": "settings_changed", "key": "<key>", "value": "<new_value>"}` to all connected clients.
  - Auto-cleanup disconnected clients. Support `Last-Event-ID` for reconnection.

## Acceptance Criteria
- [ ] Can set/get school name, address, logo URL, phone
- [ ] Flexible logo input works for both file upload and direct URL string
- [ ] SSE endpoint `/sse/events` streams events to connected clients
- [ ] Updating any setting broadcasts real-time SSE event to all subscribers
- [ ] Can CRUD bank accounts
- [ ] Can set SPP nominal and due day
