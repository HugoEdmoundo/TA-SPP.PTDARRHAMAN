## Deskripsi
Endpoint login, refresh token, logout. JWT access + refresh. Role-based: admin vs wali.

## Detail Teknis
`app/routes/auth.py`.
POST `/auth/login` (username + password → access_token + refresh_token).
POST `/auth/refresh` (refresh_token → new access_token).
POST `/auth/logout` (invalidate refresh).
`app/utils/auth.py`: `create_access_token()`, `create_refresh_token()`, `verify_token()`.
`app/dependencies.py`: `get_current_user` dependency, `require_admin` dependency, `require_wali` dependency.

## Acceptance Criteria
- [ ] Login returns JWT tokens
- [ ] Protected endpoints return 401 without token
- [ ] Admin-only endpoints return 403 for wali
