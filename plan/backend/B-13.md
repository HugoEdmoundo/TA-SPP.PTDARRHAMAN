## Deskripsi
CRUD tagihan non-SPP. Target 1 atau banyak siswa.

## Detail Teknis
`app/routes/bills.py`.
POST `/bills/non-spp` — create bill(s). Body: {student_ids: [1,2,3], category, label, description, amount, due_date, attachment (file)}. Creates one bill per student.
GET `/bills/non-spp` — list all, filter by status/student/category, pagination.
GET `/bills/non-spp/:id` — detail.
PUT `/bills/non-spp/:id` — edit (only if unpaid).
DELETE `/bills/non-spp/:id` — delete (only if unpaid).

## Acceptance Criteria
- [ ] Can create bills for multiple students at once
- [ ] Filter/search works
- [ ] Cannot edit/delete paid bills
