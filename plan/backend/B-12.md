## Deskripsi
Return tabel semua siswa × 6 bulan. For admin view.

## Detail Teknis
GET `/spp/grid?year=2025&semester=1` (semester 1 = Jul-Dec, semester 2 = Jan-Jun).
Returns array of {student_id, student_name, nis, months: [{month, status, amount_paid}]}.
Efficient query: join students with payments, group by student and month.

## Acceptance Criteria
- [ ] Returns grid for all active students
- [ ] Correct statuses
- [ ] Performant for 100+ students
