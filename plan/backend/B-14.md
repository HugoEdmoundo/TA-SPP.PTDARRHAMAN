## Deskripsi
CRUD event/patungan.

## Detail Teknis
`app/routes/events.py`.
POST `/events` — create event: {name, description, per_student_amount, student_ids, deadline, allow_installment, min_installment_amount}.
Auto-calculates total_target. Auto-generates bill records (bill_type='event') per student.
GET `/events` — list (filter by status).
GET `/events/:id` — detail.
PUT `/events/:id` — edit (only if draft/active).
DELETE `/events/:id` — delete (only if draft, deletes linked bills).

## Acceptance Criteria
- [ ] Event created with linked bills per student
- [ ] total_target calculated correctly
- [ ] Can filter by status
