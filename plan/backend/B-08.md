## Deskripsi
Endpoint siswa: CRUD with filter and search.

## Detail Teknis
`app/routes/students.py`.
GET `/students` (list, filter by is_active, search by name/NIS, pagination).
POST `/students` (create).
PUT `/students/:id` (edit).
DELETE `/students/:id` (soft delete / set is_active=false).
GET `/students/:id` (detail).
Admin-only.
