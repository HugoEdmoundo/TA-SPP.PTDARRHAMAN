| | |
|---|---|
| **Fase** | 6: Polish |

## Deskripsi
Void payment, update bill, mark receipt.

## Detail Teknis
POST `/payments/:id/void` — body: {reason}.
Set receipt is_void=true, void_reason, voided_by, voided_at.
Recalculate bill status (subtract voided amount from total_paid). If overpaid, track credit.
Log to audit trail. Admin-only.

## Acceptance Criteria
- [x] Payment voided
- [x] Bill status recalculated
- [x] Receipt marked void
- [x] Audit log created
- [x] Cannot void already-voided payments
