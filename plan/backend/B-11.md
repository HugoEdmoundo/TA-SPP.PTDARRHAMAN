## Deskripsi
Return status SPP per siswa per bulan. Hitung otomatis dari payments vs bulan sejak siswa aktif. TIDAK simpan bill record.

## Detail Teknis
`app/routes/spp.py`. `app/services/spp.py`.
GET `/spp/status/:student_id?year=2025` — return array of {month, year, nominal, total_paid, status (unpaid/partial/paid)}.
Calculate from payments table WHERE payment_type='spp' AND student_id=X AND spp_year=Y. Compare against spp_setting nominal.

## Acceptance Criteria
- [ ] Returns correct SPP status per month
- [ ] Handles partial payments (cicilan)
- [ ] Handles no payments (all unpaid)
